# 評価の根拠を固定し、追記メモを分離する

本人は発言の一貫性を重視して履歴を分析するため、文字起こし全文を原文として保持し、評価対象の会話・材料・採点基準を固定します。原文を編集して評価を更新する方式ではなく、誤変換の指摘や補足は追記メモとして分離し、採点に含めません。失敗時の手動再実行も同じ入力条件を引き継ぎ、面接後の補足で当時の説明を美化しないようにします。

## 影響

音声を保存しないため、誤変換を原音で再確認することはできません。原文は完全な音声再現とはみなさず、通信欠落と追記メモを併せて参照できるようにします。同じ入力でもAIの評価が完全に一致する保証はありません。

根拠の固定は削除を禁止する意味ではありません。本人による面接単位の削除は、[MVP仕様書](../spec/mvp.md)に従って関連記録全体に適用します。
