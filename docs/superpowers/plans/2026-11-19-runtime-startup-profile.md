# ランタイム起動内部の計測

## 目的

前回の計測で起動が支配的だった境界テストについて、起動内部の段階を同じ通常CIで測る。検査・起動順序・タイムアウト・並列度は変更しない。

## 方法

独立test環境でのみ使えるprofileStartupオプションを追加する。管理プロセス内の単調時計でロック、成果物のclaim、DB migration、ファイルと設定生成、spawn呼出、URL通知待ち、最初のHTTP応答、coverage準備、残り時間を計測する。成功した起動の数値だけを状態分離された成果物ディレクトリに保存する。

既存の計測helperがready後に読み込み、ケースの数値ログへ追加する。親側の起動時間との差分は管理プロセスの起動・IPC等として残す。読み込みに失敗した場合も起動済みランタイムを停止してから失敗する。SQL・要求・応答・生ログ・実行IDは追加出力しない。

Vite・Workerの初期化やコンパイルはURL通知待ちとHTTP応答待ちに含まれ、コンパイル単独の時間とは呼ばない。migrationには内部のDB CLI準備を含み、ファイル・設定生成はそれ以外のWeb用準備を指す。本番previewの起動計測は対象外とする。

## 検証

段階の合計、数値境界、既存計測helper、suite登録を検査する。lint・型・通常検査・文書検査を実行し、CIで対象ケースの成功と内部計測の起動件数を照合する。計測だけを行い、速度改善の変更は混ぜない。
